# KiekkoStatsit

KiekkoStatsit is an R package for hockey stats, with a focus on the Finnish Liiga.
It pulls Liiga scores, goals, shots, box scores, standings and player stats straight from liiga.fi.
It also includes NHL play-by-play and hockey-reference.com data from [hockeyR](https://github.com/danmorse314/hockeyR), the package it is built on.
Install it with `remotes::install_github("XDMAKKAra/KiekkoStatsit")`.
